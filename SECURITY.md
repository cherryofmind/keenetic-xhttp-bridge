# Конфигурации и публикация

В репозиторий принимаются только генератор, шаблоны и обезличенные описания. Не отправляйте реальные настройки, SSH-ключи, UUID, VLESS encryption/decryption, REALITY private key, QR-коды доступа, OpenVPN-профили, дампы пакетов и логи с личными адресами.

`generated/` и `*.local.json` игнорируются Git, но `git add -f`, новый каталог результата или публикация архива всей рабочей папки могут обойти ignore. Для релиза архивируйте только проверенный Git commit. Перед push проверяйте `git diff --cached` и `python tools/audit_public.py`; для личной инфраструктуры добавляйте внешнюю deny-list.

Генератор создаёт файлы с Unix-режимом 0600 и каталоги 0700, не перезаписывает существующие файлы, не печатает созданные секреты и не отправляет их на сервер. На Windows эти Unix-режимы не заменяют NTFS ACL: храните результат в защищённой папке своего пользователя.

Сканер блокирует распространённые форматы секретов и реальные публичные адреса узлов. Это дополнительный барьер, а не доказательство отсутствия любого возможного секрета. При утечке сначала отзовите доступ/смените соответствующие ключи; удаления файла из текущей ветки недостаточно для очистки истории.

Публичный issue должен содержать только обезличенное описание. Не прикладывайте рабочие данные доступа даже к «закрытому» обсуждению.
