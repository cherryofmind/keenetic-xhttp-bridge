# Чек-лист установки и устойчивости

Заполняйте по мере работы. Пустой пункт означает непроверенное условие, а не успех.
Для продолжения после паузы сначала перечитайте фактическое состояние и отчёт.

| Этап | Что должно быть подтверждено до следующего шага |
| --- | --- |
| 0. Исходное состояние | Роли двух VPS, разрешение владельца, архитектуры/версии, доступы, область LAN, DNS и старый VPN определены |
| 1. Восстановление | Копия вне роутера, отдельный VPN-экспорт, известные интерфейс/DNS, действующий резервный доступ |
| 2. Генерация | Свежие секреты созданы локально, закрыты от публикации, исходные файлы не перезаписаны |
| 3. Выход | Правильный Xray принимает `exit.json`; unit активен; порт слушает; firewall сохраняет SSH |
| 4. Вход | Правильный Xray принимает `entry.json`; unit активен; РФ достигает иностранного выхода; вход доступен клиенту |
| 5. Один клиент | С реальным клиентским профилем получен иностранный выход; работают сайты, сообщение в приложении и видео |
| 6. Роутер подготовлен | `/opt` на USB, нужные компоненты, один Xray, Hybrid, три geodata, целый confdir валиден, адреса узлов исключены |
| 7. Перед переходом | Реальный rollback соответствует исходному состоянию; таймер жив; старый VPN ещё сохранён |
| 8. Прямой путь | ISP default сохранён; обычные сайты открываются напрямую; игра не уехала в VPN из-за default route |
| 9. Выборочный путь | Без отдельного VPN на устройстве выбранные сайты и приложение работают через цепочку |
| 10. Нагрузка | Не менее 30 минут с согласованным объёмом трафика, CPU/RAM, ошибками и повторными новыми соединениями |
| 11. Обновления | Ручной запуск geodata успешен; пользовательские дополнения сохранены; одно cron-задание, часовой пояс известен |
| 12. Сохранение | Автозапуск включён после приёмки; Keenetic сохранён; таймер отменён; rollback остаётся доступен |
| 13. Повторная загрузка | После разрешённой перезагрузки `/opt` смонтирован, один Xray запущен, оба пути и приложения работают |

## Что измерять

В течение 30 минут записывайте время и часовой пояс, состояние VPN/клиента,
CPU/RAM роутера, нагрузку линии, успешные и неуспешные новые HTTPS-соединения,
поведение видео. Подберите нагрузку под оплаченный трафик и возможности роутера;
не скачивайте бессрочно и не называйте ограниченный тест измерением максимума.

Проверьте отдельно обычный российский сайт и назначения из VPN-списка.
Для проверки IP через роутер добавьте выбранный сайт проверки IP в локальное
дополнение: иначе выборочная схема вправе отправить его напрямую. Сравните с
выходом отдельного полного клиента. Убедитесь по собственным счётчикам/временному
обезличенному журналу, что тест попал в ожидаемое правило. Не включайте подробные
журналы надолго и не публикуйте историю посещений.

Клиентские проверки выполняйте при выключенном отдельном VPN на проверяемом
устройстве, сохраняя другой канал управления. Для телефона вне дома повторите
проверки через мобильную сеть. Успех телефона в Wi-Fi этого не заменяет.

HTTP 200/204 подтверждает лишь конкретный запрос. ChatGPT/WAF 403 показывает,
что получен ответ, но требует проверки входа и отправки сообщения пользователем.
Онлайн-статус службы, нулевые ошибки конфигурации, ping и скачивание одного файла
не заменяют эти пункты. Короткий пик CPU не равен отказу; длительная перегрузка,
ошибки новых соединений и остановки видео требуют отдельного разбора.

## Приватный отчёт для продолжения

Создайте `install-report.local.md` в закрытой рабочей папке. Для публичного issue
делайте отдельную обезличенную копию; полную папку в GitHub не загружайте.

```text
Версия пакета / commit:
Дата, часовой пояс, исполнитель:
Область установки и авторизация:
Компьютер, роутер, архитектура, KeeneticOS, Xray, XKeen:
Роли серверов, ОС/архитектуры (адреса только в закрытом отчёте):
Исходные VPN/DNS/default route/IPv6:
Пути к закрытым копиям и проверка их доступности:
Что изменено на каждом узле:
Результат каждого этапа 0–13 (PASS / FAIL / NOT TESTED + время):
Нагрузка: длительность, объём, диапазон скорости, CPU, ошибки:
Проверка пользователем: сайт, приложение, видео, устройство, сеть:
Команда и границы отката; состояние страховочного таймера:
Автообновление списков / автозапуск / reboot:
Оплаченные сроки VPS, автопродление по воле владельца:
Оставшиеся ограничения и следующий конкретный шаг:
```

Не вносите в отчёт пароли, приватные ключи, полные VLESS-ссылки или конфиги.
Секреты остаются в защищённых исходных файлах, в отчёте достаточно их путей.
