# Как отделить просадку скорости от других отказов

Для нового теста меняйте один фактор и записывайте время, транспорт, нагрузку и результат. Покупка другого сервера или изменение DNS до измерений затрудняет сравнение.

| Наблюдение | Следующая проверка |
| --- | --- |
| TCP установился, TLS/VLESS не завершился | Сопоставить короткие захваты заголовков на обоих концах первого плеча; отдельно проверить другой доступ в Интернет |
| Соединение долго работало, затем пауза | Одновременно CPU/RAM роутера, скорость, retransmissions/окно TCP, очередь отправки и журналы обоих VPS |
| Все сайты тормозят под нагрузкой | Проверить общий канал и CPU; прямой выход может замедляться из-за общей нагрузки без маршрутизации через VPN |
| HTTP 403 от Cloudflare | Это ответ сервера/WAF, не автоматически обрыв VPN. Подтвердить через обычный браузер и приложение |
| DNS не разрешается | Сравнить системный и назначенный DNS-профиль, кэш приложения, отдельные VPN/DNS-профили устройства |
| Роутер работает, телефон через мобильную сеть не подключается | Отдельно проверить мобильный маршрут, UDP/TCP, источник подключения, клиент и формат импорта |

Не считайте цифру загрузки достаточной приёмкой: нужны реальные сайты, приложение и несколько минут видео. Условия «PC вместо роутера», другое имя REALITY, другой клиент, другой сервер-источник или защитное ограничение нагрузки должны быть видны в таблице тестов.

В исходной диагностике часть ClientHello, видимая на захвате WAN роутера, отсутствовала в захвате РФ-входа. Это локализует участок потери, но не доказывает конкретный DPI-алгоритм или виновность одного оператора. Также наблюдалась высокая загрузка маломощного CPU и отдельные отказы CDN. Эти причины нельзя объединять в утверждение «забанили весь протокол».

Для issue достаточно:

- модель/прошивка роутера, версия Xray/XKeen, транспорт и тип доступа;
- примерное время сбоя с часовым поясом, длительность, проблема загрузки или новых соединений;
- CPU/RAM и обезличенные счётчики трафика;
- обезличенные ошибки. Удалите UUID, encryption/decryption, ключи, IP своего дома/серверов и приватные URL.
