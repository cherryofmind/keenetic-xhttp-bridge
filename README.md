# keenetic-xhttp-bridge

**Экспериментальный набор конфигураций и инструкций**, выросший из диагностики просадок домашнего VPN. Помогает воспроизвести схему с российским входом, иностранным выходом и выборочным проксированием на Keenetic.

```text
Дом / телефон
  → XHTTP + VLESS Encryption + Vision
  → ваш сервер в РФ (завершает первое соединение)
  → VLESS + REALITY
  → ваш иностранный сервер
  → Интернет
```

На Keenetic обычные назначения остаются DIRECT; выбранные домены и сервисные подсети идут через VPN. Российский узел принимает отдельное зашифрованное соединение. Это прикладной прокси, простой DNAT не воспроизводит эту схему.

## Что внутри

- Генератор новых ключей и профилей для двух серверов, Keenetic/XKeen и мобильного клиента.
- Домены Re:filter и ZKeen, отдельный файл пользовательских дополнений, ежедневное обновление через штатный механизм XKeen.
- Пример отката на сохранённый OpenVPN и инструкции по проверке перед переключением.
- Проверки генератора и публикационный сканер секретов. Готовые доступы к чужим серверам не предоставляются.

Это конфигурационная надстройка над [Xray-core](https://github.com/XTLS/Xray-core) и [XKeen](https://github.com/jameszeroX/XKeen). Авторы этих проектов не участвуют в этом репозитории и не подтверждали его работоспособность. Исходная задача возникла при эксплуатации [AntiZapret-VPN](https://github.com/GubernievS/AntiZapret-VPN); его серверные скрипты здесь не изменяются и не распространяются.

релиза и [готовое сообщение из AI_INSTALL.md](docs/AI_INSTALL.md). Короткий вариант:

```text
Установи мне https://github.com/cherryofmind/keenetic-xhttp-bridge.
Прочитай README.md, AGENTS.md, docs/AI_INSTALL.md, docs/INSTALL.md,
```

## Быстрый старт

Нужны два своих VPS и Keenetic с Entware на USB/EXT4. Перед покупками проверьте уже имеющиеся серверы. Генератор требует Python 3.10+ и установленный официальный Xray. На рабочий роутер он сам ничего не устанавливает.

```sh
# На защищённом компьютере с установленным Xray:
python tools/render.py init --xray /usr/local/bin/xray \
  --entry-host YOUR_RU_VPS --exit-host YOUR_FOREIGN_VPS
python tools/render.py render
```

Для проверенной MIPS-модели можно добавить `--mips-router` при генерации настроек. Этот параметр включает платформенные Linux/MIPS socket options только в роутерном профиле. Для ARM, x86 и телефона его не используйте.

Результат появится в игнорируемом `generated/`, исходные секреты — в игнорируемом `settings.local.json`. Существующие файлы не перезаписываются. Это только генерация; дальше следуйте [полной установке](docs/INSTALL.md).

## Что проверено на 30 октября 2026

| Проверка | Результат и предел вывода |
| --- | --- |
| XHTTP + VLESS Encryption + Vision на Keenetic Extra KN-1713, KeeneticOS 5.1.8, Xray 26.10.29, XKeen 2.1 | Исходная конфигурация успешно применена вручную; установка этой упакованной версии на чистом стенде ещё не пройдена |
| 30 минут контролируемой нагрузки через роутер | Около 1,23 ГБ; без зарегистрированных сетевых ошибок; 57 новых HTTPS-соединений успешны. Нагрузка ограничивалась для защиты CPU; максимум скорости этим тестом не установлен |
| 10 минут после переключения домашней сети | 160 коротких HTTPS-проверок без транспортных ошибок; средний CPU около 49%, семь из 120 интервалов ≥95%. Это не приёмка всех сайтов или видео |
| Старые REALITY-варианты на том же роутере | В одном прогоне пауза около 18 секунд; в других не завершались отдельные TLS-приветствия. Точный виновник потери пакетов не установлен |
| Xray 26.10.21, версия ядра заявленного мобильного клиента | Проверка конфигурации и несколько HTTPS-запросов на ПК прошли. iPhone и мобильная сеть отдельно не подтверждены |

В длительном тесте на втором плече использовалось другое имя REALITY; после возврата к исходному имени выполнены короткие проверки и наблюдение, новый 30-минутный тест не повторялся. Все результаты относятся к конкретному каналу и оборудованию. Генератор проверен локальными тестами и проверкой конфигураций Xray. Шаблон GitHub Actions включён отдельно в документацию.

Гарантии обхода DPI нет. Замена OpenVPN на XHTTP не устраняет слабый CPU роутера, перегрузку канала, проблему CDN или фильтрацию IP. [Как диагностировать просадки и сообщить об ошибке](docs/DIAGNOSTICS.md).

## Разработка и безопасность

```sh
python -m unittest discover -s tests -v
python tools/audit_public.py
```

Сканер проверяет отслеживаемые Git файлы. Дополнительный `--deny-file /PRIVATE/PATH/deny.json` принимает локальный JSON-массив запрещённых значений; сам файл остаётся вне репозитория. При отправке issues приложите обезличенную диагностику согласно [SECURITY.md](SECURITY.md).

Необязательный шаблон GitHub Actions — `docs/ci-workflow.example.yml`; для включения его нужно разместить в `.github/workflows/check.yml` с соответствующими правами GitHub. В первом выпуске автоматический CI не включён.
