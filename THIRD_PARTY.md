# Внешние проекты

Этот репозиторий распространяет собственный генератор, инструкции и вспомогательные сценарии под MIT. Бинарники, исходники ядер, код XKeen и базы доменов/IP в него не включены.

| Проект | Назначение | Источник и лицензия |
| --- | --- | --- |
| Xray-core | VLESS, XHTTP, VLESS Encryption, REALITY, Vision | [Исходники](https://github.com/XTLS/Xray-core), [MPL-2.0](https://github.com/XTLS/Xray-core/blob/main/LICENSE) |
| XKeen (jameszeroX) | Интеграция Xray с Keenetic/Entware и Netfilter | [Исходники](https://github.com/jameszeroX/XKeen), [BSD-3-Clause](https://github.com/jameszeroX/XKeen/blob/main/LICENSE) |
| Corvus-Malus/XKeen | Подробное руководство Keenetic | [README](https://github.com/Corvus-Malus/XKeen) |
| Re:filter | Обновляемый список доменов | [Проект и условия](https://github.com/1andrevich/Re-filter-lists), [geosite.dat](https://github.com/1andrevich/Re-filter-lists/releases/latest/download/geosite.dat) |
| ZKeen | Компактные сервисные списки и исключения | [Проект и условия](https://github.com/jameszeroX/zkeen-domains), [zkeen.dat](https://github.com/jameszeroX/zkeen-domains/releases/latest/download/zkeen.dat) |
| ZKeenIP | Сервисные подсети | [Проект и условия](https://github.com/jameszeroX/zkeen-ip), [zkeenip.dat](https://github.com/jameszeroX/zkeen-ip/releases/latest/download/zkeenip.dat) |
| Entware | Пакеты для USB-среды роутера | [Проект](https://github.com/Entware/Entware); лицензии отдельных пакетов |
| AntiZapret-VPN | Исходная задача/альтернативная архитектура | [Проект](https://github.com/GubernievS/AntiZapret-VPN); код здесь не заимствуется |

Соблюдайте актуальные условия внешних проектов при загрузке и использовании их компонентов. Это независимый набор конфигураций, не официальный выпуск перечисленных проектов.

Авторы ZKeen отдельно указывают ограничение коммерческой эксплуатации в README своего проекта. Данные здесь не распространяются; проверьте условия внешних списков для собственного сценария использования.
